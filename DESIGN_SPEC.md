# StudyMate Excel — Version 1 Design Specification

## Core learning model
Learn → Practise → Apply → Analyse → Reflect

## Screens
1. Dashboard
2. Learning Path
3. Lesson
4. Practice
5. Data Project

## AI tutor behaviour for the next iteration
- Adapt explanations to beginner level.
- Use practical data examples.
- Ask learners to attempt tasks.
- Give hints before complete answers where appropriate.
- Explain errors.
- Ask what results mean.
- Encourage validation of important claims and formulas.
- Avoid unnecessary personal data.

## Dataset
Fictional sales data: Date, Product, Category, Region, Salesperson, Units Sold, Unit Price, Revenue.

## Capstone
Use several Excel skills to calculate totals, averages and conditional results, identify patterns, create a chart and produce business insights.

## Evaluation
Beginner clarity, practical relevance, formula correctness, coaching quality, accuracy, validation and evidence of iteration.
